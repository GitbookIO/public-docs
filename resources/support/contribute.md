# Contribute to the docs

Thank you for investing your time in contributing to GitBook’s documentation. Every contribution is reviewed by the team.

This documentation is published with GitBook, using [Git Sync](../../getting-started/git-sync/) to keep the site up to date with the `public-docs` repository on GitHub. Any change that’s reviewed, approved, and merged into the repository is deployed automatically.
