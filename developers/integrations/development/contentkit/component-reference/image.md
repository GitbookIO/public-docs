# Image

```tsx
<image source={{ url: "https://example.com/image.png" }} aspectRatio={16 / 9} />
```

| Props           | Type     | Description         |
| --------------- | -------- | ------------------- |
| `source`\*      | `object` | Image source.       |
| `source.url`\*  | `string` | Image URL.          |
| `aspectRatio`\* | `number` | Image aspect ratio. |
