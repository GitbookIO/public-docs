# Text

```tsx
<text>Hello <text style="bold">World</text></text>
```

| Props        | Type                                              | Description       |
| ------------ | ------------------------------------------------- | ----------------- |
| `children`\* | `Array<string \| Text>`                           | Text content.     |
| `style`\*    | `"bold" \| "italic" \| "strikethrough" \| "code"` | Formatting style. |
