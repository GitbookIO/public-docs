# Divider

```tsx
<divider />
```

| Props   | Type                             | Description                    |
| ------- | -------------------------------- | ------------------------------ |
| `style` | `"default" \| "line"`            | Visual style.                  |
| `size`  | `"medium" \| "small" \| "large"` | Spacing. Defaults to `medium`. |
