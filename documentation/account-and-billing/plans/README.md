# Plans

GitBook allows you to publish documentation on different plans. Each site plan contains different features, including advanced customization, AI features, and more. You can pay for additional users on any paid plan.

Find the full feature table on our pricing page.

<a href="https://www.gitbook.com/pricing" class="button secondary">Visit pricing page</a>

Eligible non-profit, open-source, and education-related organizations can apply for the free [Community plan](community/). It includes all Ultimate plan features except SAML SSO.

{% hint style="info" %}
The Essential plan was previously called Premium. Existing Premium sites are now Essential sites, with the same features.
{% endhint %}

{% hint style="info" %}
Prices shown are for annual billing. With monthly billing, Essential is $79 per site/month, Ultimate is $299 per site/month, and each additional user is $15 per user/month. For full details, see our [pricing page](https://www.gitbook.com/pricing).
{% endhint %}

AI Assistant Ask is available on Essential and Ultimate site plans. AI Assistant Chat, AI insights, and channels are available on Ultimate.

AI features use [AI credits](ai-credits.md). Each Essential site includes 2,000 credits per month, and each Ultimate site includes 10,000. If you need more, you can add a monthly credit pack.

### Add-ons

{% hint style="warning" %}
The Translations add-on is only available to organizations on legacy pricing. On current plans, auto-updating translations use AI credits.
{% endhint %}
