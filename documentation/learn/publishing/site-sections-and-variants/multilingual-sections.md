# Multilingual sections

Localized titles show a different title for your site, a section, or a section group, depending on the language a visitor is browsing in. If no translation is set for their language, GitBook falls back to the default title.

{% hint style="info" %}
Localized titles only appear when your site includes content in more than one language.
{% endhint %}

### Set up localized titles

{% stepper %}
{% step %}
#### Open the structure editor

From your docs site, open **Site structure**, under **General** in the site sidebar.
{% endstep %}

{% step %}
#### Find the title you want to translate

Open the title field for your site, a section, or a section group.
{% endstep %}

{% step %}
#### Set the fallback title

By default, this is the current section name.
{% endstep %}

{% step %}
#### Add each translated title

Open the language selector, choose a language, and enter the title for it. Repeat for each language you support.
{% endstep %}
{% endstepper %}

When adding a translation or multiple languages as a [variant](README.md), set the variant's language so readers get the best navigation experience. Adding multiple language variants moves the language picker to the upper right, for a cleaner experience than the default variant picker. Variant titles can be translated the same way, so the picker shows localized labels.
