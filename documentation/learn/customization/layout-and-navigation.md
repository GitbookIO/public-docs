# Layout and navigation

### Header

**Search bar** — position it prominently (centered in the header) or subtly (upper right corner). Turning off the header entirely moves the search bar into the sidebar.

**Navigation** — add header links to important parts of your documentation, or back to your main website. Choose an appearance for each — normal link, primary button, or secondary button — and add a title and URL. Two levels of header navigation are supported, so sub-links can appear in a dropdown.

### Announcement

{% hint style="info" %}
Available on Premium and Ultimate plans.
{% endhint %}

Add a banner to the top of your published site, with a message and an optional link/call to action after it. Style it like a hint block — Info, Warning, Danger, or Success — colored by your semantic colors settings.

### Pagination

Control the "previous" and "next" buttons at the bottom of each page, site-wide or per page.

### Footer

{% hint style="info" %}
Available on Premium and Ultimate plans.
{% endhint %}

**Logo** — add your logo or another image to the footer.

**Copyright text** — add copyright information.

**Navigation** — add footer links organized into multiple sections, each with a title and URL, plus a section title for each group.
