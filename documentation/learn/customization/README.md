# Customization

{% hint style="info" %}
Advanced customization options are available on Premium and Ultimate plans.
{% endhint %}

You can customize your published documentation's appearance, match the interface to your content's language, and more — applied site-wide as a theme, or per variant and site section.

### Customizing sites with multiple sections or variants

If your docs site has multiple sections or variants, customize each one individually. Select the whole site or a specific section from the dropdown at the top of the **Customization** panel.

* **Site-wide settings** apply to all sections automatically.
* **Section or variant-specific settings** override the site-wide default for that section or variant.

{% hint style="warning" %}
Changes to a specific section override the site-wide setting, even if you change the site-wide setting again later. Reset a section back to the site-wide default with the **Reset** button next to the section selector.
{% endhint %}

### What counts as "advanced customization"?

Every GitBook user gets basic customization options. Premium or Ultimate site plans add advanced customization to further match your brand:

* **Custom logo** — replace the emoji and title at the top of your site.
* **Icon style** — change the weight and style of page icons.
* **Custom fonts** — change the primary and monospace fonts.
* **Footer** — add a logo, copyright text, and navigation.
* **Bold and Gradient themes** — a colored header background, or a gradient across the whole site.
* **Semantic colors** — change hint block and code block styling.
* **Code themes** — preset or adaptive themes for code and API blocks.

See [Themes, colors, and typography](themes-colors-typography.md), [Layout and navigation](layout-and-navigation.md), and [Social sharing and custom code](social-sharing-and-custom-code.md) for the details, and the [site settings reference](site-settings-reference.md) for everything else.

### What can't be customized

Regardless of plan:

1. You can't customize the layout of elements on the page — though you can [hide certain elements on specific pages](../creating-content/content-structure.md).
2. You can't insert custom code (CSS, HTML, or JS) directly into your site. GitBook integrates with a number of popular tools already, and offers [rich embeds](../creating-content/blocks/embed-a-url.md) for many more.
3. You can't remove the small "Powered by GitBook" link in published documentation.
