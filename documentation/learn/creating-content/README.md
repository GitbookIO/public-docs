# Creating content

To format your text, select the words you want and choose a format from the context menu — or use a keyboard shortcut or Markdown syntax.

{% hint style="info" %}
Shortcuts below use Mac keys. Use **Control** instead of **⌘ (Command)** on Windows or Linux — see [Keyboard shortcuts](../../resources/keyboard-shortcuts.md) for every shortcut on every OS.
{% endhint %}
