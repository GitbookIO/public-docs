# The editor

GitBook's editor is block-based: every piece of content on a page — text, images, tables, code, API references, embeds, and more — exists in its own block. You can mix any combination of blocks on a page, in any order, with no limit on how many you use. See [Blocks](blocks/README.md) for the full list.

You can write in two ways, interchangeably:

* **Visually** — insert and format blocks directly through the editor's menus, context menu, and keyboard shortcuts.
* **In Markdown** — GitBook supports writing and formatting with Markdown syntax, so you can type `**bold**` or `# Heading` instead of reaching for a menu. See [Markdown reference](markdown-reference.md).

Editing is real-time and collaborative: multiple people can work on the same content together when [live edits](../collaboration/comments-and-live-editing.md#live-editing) are unlocked, and [comments](../collaboration/comments-and-live-editing.md) let you discuss content without leaving the page. For published or more carefully governed content, edits go through [change requests](../collaboration/change-requests/README.md) instead — a branch-like workflow with review before anything goes live.

Everything you write is also tracked: [version history](version-history-and-page-tags.md) records every change, so you can see what happened and roll back if needed.
