# Unordered list

Unordered lists are great for a series of points that don't need a particular order — bullet-point lists, with support for nesting.

Hit `Enter` twice to exit the list and start a new empty block below.

### Example

* Item
  * Nested item
    * Another nested item
  * Yet another nested item
* Another item
* Yet another item

{% hint style="info" %}
Use **Tab** to indent a nested item, and **⇧+Tab** to outdent.
{% endhint %}

### Representation in Markdown

```markdown
- Item
   - Nested item
      - Another nested item
   - Yet another nested item
- Another item
- Yet another item
```
