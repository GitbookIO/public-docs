# Blocks

GitBook is a block-based editor — every piece of content on a page, from standard text and images to interactive blocks, is its own block. Mix any combination of blocks on a page, with no limit on how many you use.

### Inserting a new content block

Hover over the block above where you want new content, and click the `+` icon that appears on the left to open the insert palette, then choose a block. Or, on a new line, press `/` to open the same palette — scroll or type to search, then insert with `Enter`.

### Exiting a block

Some blocks capture the cursor so you can add content in their context — for example, in a [hint block](hint.md), hitting `Enter` adds a new line inside the hint instead of a new paragraph below. Continue adding content to the page by inserting a new block with the `+` button, or by hitting ⌘+Enter (Mac) / Ctrl+Enter (PC).

### Selecting blocks and interacting with them

Press `Esc` with your cursor in a block to select it, or highlight content across multiple blocks and hit `Esc` to select them all. Once selected:

* Click while holding **Shift** to select more blocks.
* Use **↑** / **↓** to move the selection up or down.
* Copy with ⌘+C (Mac) or Ctrl+C (Windows).
* Cut with ⌘+X (Mac) or Ctrl+X (Windows).
* Delete with ⌫ or Del.
