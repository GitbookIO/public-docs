# Math & TeX

Include mathematical formulae using the mathTeX format, rendered with the [KaTeX](https://katex.org/docs/supported.html) library. You can also add mathTeX as [inline content](../format-your-content.md).

### Example

$$
s = \sqrt{\frac{1}{N-1} \sum_{i=1}^N (x_i - \overline{x})^2}
$$

### Representation in Markdown

```markdown
# Math and TeX block

$$f(x) = x * e^{2 pi i \xi x}$$
```
