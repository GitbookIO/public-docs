# Ordered list

Ordered (numbered) lists help you prioritize items or lay out a sequence of steps.

### Example

1. Item 1
   1. Nested item 1.1
      1. Nested item 1.1.1
   2. Nested item 1.2
2. Item 2
3. Item 3

{% hint style="info" %}
Use **Tab** to indent a nested item, and **⇧+Tab** to outdent.
{% endhint %}

### Representation in Markdown

```markdown
1. Item 1
   1. Nested item 1.1
      1. Nested item 1.1.1
   2. Nested item 1.2
2. Item 2
3. Item 3
```

### Adding an inline image to an ordered list

You can add an image inside an ordered list. Insert it from the insert menu, then on the row below, type the next number (e.g. `3.`) and hit `Space` to continue the list.
