# Updates

An updates block lets you add a changelog to any page. Each update has a date, optional tags, and supports any block content inside it — text, images, code blocks, lists, and more.

### Adding updates

Insert an updates block on any page. Once it's there, hover above or below an existing update to add another in sequence.

Click the date in the block to change its format — full date, shortened, or numbers only (e.g. `12/25/2025`).

### Tags

Each update can have its own tags — use the tag picker below the date to add, remove, or reorder them. See [Version history and page tags](../version-history-and-page-tags.md#page-tags).
