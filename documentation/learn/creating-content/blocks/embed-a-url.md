# Embed a URL

Paste the URL of content you want to embed, and hit `Enter`.

{% hint style="info" %}
The content must be publicly accessible for GitBook to embed it — for a Google Doc, for example, sharing must be set to "Anyone with the link."
{% endhint %}

Supports YouTube, Codepen, Spotify, and other embeddable URLs.

{% hint style="info" %}
Auto-play and loop a YouTube or Vimeo embed by adding `?autoplay=1&loop=1` to the end of its URL.
{% endhint %}

### Representation in Markdown

```markdown
{% embed url="URL_HERE" %}
```
