# Paragraph

A paragraph is the most basic content block in GitBook.

{% hint style="info" %}
Add [other inline content](../format-your-content.md) to a paragraph, like emojis, images, and Math & TeX — or [format your text](../format-your-content.md) with the context menu, keyboard shortcuts, or [Markdown](../markdown-reference.md).
{% endhint %}

### Example

Professionally printed material in English typically does not indent the first paragraph, but indents those that follow. For example, Robert Bringhurst states that we should "set opening paragraphs flush left."

### Representation in Markdown

Because a paragraph block is just text, that's how it's represented in Markdown:

```markdown
Professionally printed material in English typically does not indent the first paragraph, but indents those that follow. For example, Robert Bringhurst states that we should "set opening paragraphs flush left."
```
