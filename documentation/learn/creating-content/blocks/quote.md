# Quote

Quotes are useful for including something from another source.

Start one by typing `>` then `Space` in an empty paragraph, using the [insert palette](README.md#inserting-a-new-content-block), or by selecting an entire paragraph and hitting `>` to convert it.

### Example

> "No human ever steps in the same river twice, for it's not the same river and they are not the same human." — _Heraclitus_

### Representation in Markdown

```markdown
> "No human ever steps in the same river twice, for it's not the same river and they are not the same human." — _Heraclitus_
```
