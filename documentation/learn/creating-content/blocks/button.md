# Button

Buttons highlight calls to action, or add a search or Ask AI bar to your docs — they can send readers somewhere, or help them find answers. These actions work on published pages too.

### Button actions

* **Link** — send readers to another page or an external URL.
* **Search bar** — open search with an optional preset query.
* **Ask AI / GitBook Assistant bar** — open GitBook Assistant with an optional preset prompt.
* **Disabled** — show a button that's intentionally inactive.

### Create and configure a button

1. Type `/` and choose **Button**.
2. Click the button to open the **Label** menu.
3. Choose an action, then set the label and style.
4. Optionally, add a preset search query or Assistant prompt.

### Styles

Link and disabled buttons support both primary and secondary styles.

### Representation in Markdown

```markdown
<a href="https://app.gitbook.com" class="button primary">GitBook</a>
```
