# Document APIs

GitBook turns an OpenAPI (or Swagger) specification into interactive, testable API reference pages — no need to hand-write REST API documentation.

* [How GitBook renders OpenAPI](how-gitbook-renders-openapi.md) — the concept, and which spec versions are supported.
* [Add an OpenAPI spec and insert references](add-an-openapi-spec.md) — get a spec into GitBook and generate pages from it.
* [Structure your API reference](structure-your-api-reference.md) — control layout, navigation, and operation visibility.
* [Code samples and enum descriptions](code-samples-and-enums.md) — customize what readers see per operation.
* [Automate spec updates with CI/CD](automate-spec-updates.md) — keep your spec current automatically.
* [OpenAPI extensions](openapi-extensions.md) — the full reference of GitBook's `x-` extensions.
* [Configure the "Test it" button](configure-the-test-it-button.md) and [use the OpenAPI proxy](use-the-openapi-proxy.md) — tune or troubleshoot the interactive request runner.
