# GitBook Assistant

{% hint style="info" %}
GitBook Assistant is available on the Ultimate plan.
{% endhint %}

GitBook Assistant gives your readers fast, accurate answers about your documentation using natural language. It's personalized to your users, can be embedded into your website or product, and lives in the sidebar of your published docs — a product expert available wherever and whenever your users need it.

Assistant uses agentic retrieval to understand the context of a query based on the reader's current page, previously read pages, and previous conversations.

### Using GitBook Assistant in published docs

Readers can access it three ways:

* Press ⌘+I on Mac or Ctrl+I on PC.
* Click the **GitBook Assistant** button next to the **Ask or search…** bar.
* Type a question into the **Ask or search…** bar and choose the "Ask…" option at the top of the menu.

### Embed GitBook Assistant in your product

Embed Assistant directly into your product or website via [Docs Embed](../../embed/README.md), which includes the Assistant tab alongside Search and Docs tabs. See [Install the embed](../../embed/install-the-embed.md) for setup by integration method, [Authenticate the embed](../../embed/authenticate-the-embed.md) if your docs need sign-in, and [Customize the embed](../../embed/customize-the-embed/README.md) for welcome messages, actions, and suggestions.
