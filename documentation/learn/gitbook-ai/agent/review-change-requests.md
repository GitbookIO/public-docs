# Review change requests with Agent

Beyond [creating content](write-and-edit.md), GitBook Agent can review your change requests to quickly find and fix errors, suggest improvements, and more. It understands the context of the rest of your docs, and you can add your team's [style guide](style-guide.md) so it reviews changes while sticking to your team's style.

### Review change requests with GitBook Agent

Request a review from Agent on any [open change request](../../collaboration/change-requests/README.md#browsing-change-requests-across-your-site) in your site — open it and add Agent as a reviewer. It goes through your changes and reviews for accuracy, clarity, and more, using the context of your published site and style guide.

To inspect the changes yourself, open the change request in the editor and switch to the **Changes** tab — pages with diffs show an indicator, and a floating diff navigation control helps you jump between changed blocks.

If Agent suggests further changes, ask it to implement them — either [through the chat window](write-and-edit.md#how-to-interact-with-gitbook-agent) or by [tagging it in a comment](write-and-edit.md#how-to-interact-with-gitbook-agent). Once you're happy, [merge the change request](../../collaboration/change-requests/review-and-merge.md#merging-a-change-request) to publish live.

### Update change requests with GitBook Agent

Agent works with you like another team member. [Inside a change request](../../collaboration/change-requests/create.md), [open its chat window](write-and-edit.md#how-to-interact-with-gitbook-agent) to start collaborating. Ask it to:

* Write new content or expand existing sections.
* Fix typos and spelling errors.
* Rewrite unclear or outdated explanations.
* Review pages for accuracy, clarity, and completeness.
* Generate or update code examples.
* Identify missing docs or gaps in workflows.

See [Write and edit with Agent](write-and-edit.md) for more.
