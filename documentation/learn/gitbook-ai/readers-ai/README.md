# Your docs, readers' AI

Every GitBook site is automatically built to work well with AI tools — your readers', not just your own. This section covers optimizing your *published* docs for consumption by LLMs, coding agents, and MCP clients that your readers bring to your content.

* [Make your docs agent-ready](make-your-docs-agent-ready.md) — the automatic `.md` pages, `llms.txt`, and `llms-full.txt`, plus best practices.
* [MCP server for published docs](mcp-server-for-published-docs.md) — let readers' AI tools query your docs directly over MCP.

{% hint style="info" %}
This is the *reader-side* MCP server — for querying your published content. If you're looking to connect your own AI coding assistant to *author* GitBook content instead, see Build with AI → GitBook MCP → Connect your client.
{% endhint %}
