# Agent vs. Assistant

GitBook Agent and GitBook Assistant are both AI features, but they work on opposite sides of your documentation:

| | GitBook Agent | GitBook Assistant |
|---|---|---|
| **Who it's for** | You and your team — the people writing docs | Your readers — the people using your docs |
| **Where it lives** | Inside the GitBook app, in change requests and comments | On your published site, in the sidebar or search bar |
| **What it does** | Writes, edits, reviews, translates, and audits content on your behalf | Answers questions using your docs (and connected sources) as context |
| **What it changes** | Your documentation itself, via change requests | Nothing — it only answers, it doesn't edit |

If you're asking "how do I get help writing or fixing a page," you want [GitBook Agent](agent/README.md). If you're asking "how do my readers get help finding an answer," you want [GitBook Assistant](assistant/README.md).

They can work together: Assistant surfaces where readers get stuck, and Agent can turn those gaps into fixes — see [Run an Agent audit](agent/run-an-audit.md) and [Fix gaps with GitBook Agent](../analytics/insights/fix-gaps-with-agent.md).
