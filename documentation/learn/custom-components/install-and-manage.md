# Install and manage

You can install an integration in a single section, multiple sections, or all the sections across your organization. Installing in a single section means it only works there; installing in multiple sections lets you perform actions across all of them.

### Install an integration

{% stepper %}
{% step %}
#### Open the integrations screen

Before enabling an integration in a section or site, install it in your organization first. Go back to your organization **Home** and click **Integrations** in the sidebar. Browse by category, or search for the one you need.

Once an integration is installed in your organization, you can also work with it at the site level — click **Integrations**, under **Extend** in the site sidebar. Integrations already added to the site appear under **Installed integrations**.
{% endstep %}

{% step %}
#### Select the integration and install

Click the integration you want. Some integrations install for your sections, others for your published documentation — this screen lets you choose which areas to install it in.
{% endstep %}

{% step %}
#### Configure your integration

Some integrations need extra configuration after installing — if so, you'll see a prompt to configure it in your section or site. Check the integration's own instructions for details on configuring it for your team.
{% endstep %}
{% endstepper %}
