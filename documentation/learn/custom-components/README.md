# Custom components

From interactive content blocks to advanced analytics tools, GitBook has [many integrations](https://www.gitbook.com/integrations#custom-experiences) you can add to your sections and sites in a click.

* [Install and manage](install-and-manage.md) an existing integration from GitBook's library.
* [Build your own](build-your-own.md) integration or ContentKit component, if you need something custom.
