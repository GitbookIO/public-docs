# Embed GitBook in your product

The Docs Embed puts your documentation and GitBook Assistant inside your own product or website, so users get answers without leaving your app.

* [What the Docs Embed is](what-the-docs-embed-is.md) — the concept, and what's inside it.
* [Install the embed](install-the-embed.md) — script tag, Node.js/NPM, or React.
* [Authenticate the embed](authenticate-the-embed.md) — for docs behind authenticated access.
* [Customize the embed and add custom tools](customize-the-embed/README.md) — tailor the UI, and let the Assistant take real actions in your product.
* [Embed API reference](embed-api-reference.md) — every method and option, across all three integration methods.

For the complete API reference and source code, see the [`@gitbook/embed` package on GitHub](https://github.com/GitbookIO/gitbook/tree/main/packages/embed).
