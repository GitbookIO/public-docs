# Query the Events Aggregation API

Beyond the [Analytics](README.md) screen in the GitBook app, you can query your site's aggregated analytics events programmatically — useful for feeding traffic, search, and feedback data into your own dashboards or reporting pipelines, rather than working from the UI alone.

Requests are authenticated the same way as the rest of the GitBook API — see **Developers → API → Authentication** for authentication and general API usage.
