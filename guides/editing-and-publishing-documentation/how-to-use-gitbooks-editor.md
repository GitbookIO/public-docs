# How to use GitBook’s editor

GitBook’s editor makes it easy to create and customize documentation, whether you’re starting fresh or working in an existing space.

This video and guide will take you through GitBook’s native editor, covering:

* Creating [change requests](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/collaborate/change-requests) to edit content
* Editing [page titles, descriptions, and icons](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/create-content/content-structure/page#pages)
* Configuring [page options and layouts](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/create-content/content-structure/page#page-options)
* Changing a page’s [visibility and indexing settings](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/create-content/content-structure/page#visibility)
* Adding and editing [blocks](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/create-content/blocks#inserting-a-new-content-block), [Markdown](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/create-content/formatting/markdown), and content
* Syncing edits with [Git Sync](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/docs-as-code/git-sync)
* and more!

{% step %}
### Start a new change request

To edit published content, start by creating a **new change request**. This gives you a dedicated place to make and review edits, without pushing them live right away.

If you’re new to the workflow, start with [change requests](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/collaborate/change-requests).
{% endstep %}

{% step %}
### Set up your page

You can set the **page title** at the top. This is what readers see in the sidebar.

You can also add a **page description** and an [icon/emoji](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/create-content/content-structure/page#add-an-icon-or-emoji-to-your-page).
{% endstep %}

{% step %}
### Configure page options

Open [**Page options**](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/create-content/content-structure/page#page-options) to control layout and presentation.

Use it to pick a **layout** (including templates like landing pages). You can also switch block width between **default** and **full width**.

If you need a cleaner view, hide the page title, description, sidebars, or footer. These overrides apply only to the current page.
{% endstep %}

{% step %}
### Control page visibility

GitBook gives you fine-grained control over who can see content. You can hide a page from **navigation** but still share it via a direct link.

You can also control discoverability:

* Include or exclude the page from [**search indexing**](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/create-content/content-structure/page#visibility).
* Allow or block [**web crawling**](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/create-content/content-structure/page#visibility) (for tools like Google or ChatGPT).
{% endstep %}

{% step %}
### Edit content with blocks

You can start typing to add content at any time.

Type `/` to open the [**block insert menu**](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/create-content/blocks#inserting-a-new-content-block), then search for what you need. Common blocks include tables, cards, expandables, tabs, and more.

If you prefer keyboard-first formatting, GitBook supports [Markdown](https://app.gitbook.com/s/NkEGS7hzeqa35sMXQZ4X/create-content/formatting/markdown) too.
{% endstep %}

{% step %}
### Add integrations and advanced content

The insert menu also lets you pull in more powerful content:

* **Integrations** installed in your space (GitHub files, forms, embeds)
* **Reusable content** for shared snippets
* **OpenAPI specifications** for interactive API docs
{% endstep %}
