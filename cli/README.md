# CLI

The GitBook CLI (`@gitbook/cli`) wraps the GitBook API as a set of terminal commands. Use it two ways:

* **Work with GitBook content** — list organizations and spaces, read pages, ask questions against your docs, and script anything the API can do, with output formats built for both humans and scripts.
* **Build and publish integrations** — scaffold a new integration, run it locally against a test space, and publish it to the Developers → Custom components platform.

{% hint style="info" %}
Want an AI agent to work with GitBook conversationally instead of via commands? See Build with AI → GitBook MCP.
{% endhint %}
