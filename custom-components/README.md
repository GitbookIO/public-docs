# Custom components

{% hint style="info" %}
Looking for the CLI or the REST API instead? See Developers → CLI and Developers → API.
{% endhint %}

GitBook's developer platform lets you build integrations — TypeScript apps that extend GitBook with custom UI components, event handling, OAuth flows, and HTTP communication. Use it to:

* Automate repetitive tasks — sync content, manage permissions, or trigger actions without leaving GitBook.
* Embed interactive components — enhance pages with custom-built UI, buttons, and dynamic content, using ContentKit.
* Integrate data from other tools — pull in data from external sources and connect it to your GitBook workflow.
* Securely connect systems — handle authentication via OAuth and manage access programmatically.

* [Build your first integration](getting-started/build-your-first-integration.md) — a hands-on quickstart.
* [Integration concepts](integration-concepts.md) — the vocabulary and manifest file.
* [ContentKit overview](contentkit/contentkit-overview.md) and [Component reference](contentkit/contentkit-component-reference.md) — build custom UI.
* [Guides](guides/README.md) — link unfurling, interactive blocks, webhooks, and HTTP requests.
* [Integration runtime reference](integration-runtime-reference.md) — the full API surface (`createIntegration`, `createComponent`, events, and more).
* [Publishing and submitting integrations](publishing-and-submitting-integrations.md) — share your integration with your org or the marketplace.
